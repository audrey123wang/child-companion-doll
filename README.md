# 儿童陪伴娃娃原型资料

这个私有仓库汇总 M5StickC Plus 1.1 开发板上的儿童陪伴娃娃产品探索资料和实验源码。目前是验证原型，不是可交付给儿童使用的量产产品。

- [产品需求文档](儿童陪伴娃娃产品需求文档.md)：家长与儿童共用 App、时间设置、日/周报告、故事与聊天。
- [软硬件系统架构方案](儿童陪伴娃娃软硬件系统架构方案.md)：设备、App、云端的分工与数据流。
- [开放资料借鉴清单](儿童陪伴产品开放资料借鉴清单.md)：可参考的开源项目与内容来源。
- [当前表情方案预览](硬件表情方案预览.png)：B「奶油圆脸猫」视觉方向。

## 实验源码

- [当前板载功能演示](M5StickCPlusHardwareDemo/README.md)：表情、按键、麦克风音量条和蜂鸣器，已在连接的设备上验证。
- [按键收音及联网固件实验](M5StickCPlusListeningFirmware/src/main.cpp)：含 BLE 配置、Wi-Fi 上传及板载表情的实验代码。

## 数据与安全

仓库仅包含文档、源码及表情预览。未上传设备 Flash/NVS 备份、编译产物、应用包、Wi-Fi 密码、网关访问令牌或云服务密钥。实验源码中的凭据由运行时配置提供。与儿童相关的真实录音、逐字稿和报告也不应提交到仓库。
