# M5StickC Plus 1.1 本机功能演示

演示固件已刷入当前 USB 连接的开发板。按用户选择，表情页采用 B「奶油圆脸猫」风格。固件不连接网络，不保存或上传音频；上电后屏幕显示猫咪表情。

| 操作 | 屏幕表现 | 硬件能力 |
| --- | --- | --- |
| 按侧边 B 键 | 表情 → 麦克风音量条 → 设备状态，循环切换 | 按键和 LCD |
| 表情页按正面 A 键 | 开心、好奇、困倦、倾听表情循环，并发出短提示音 | LCD 和无源蜂鸣器 |
| 麦克风页在板子附近说话 | 绿色音量条随声音变化 | 内置麦克风；只在 RAM 中计算音量 |
| 设备状态页按 A 键 | 播放短音，显示电池电压、当前无线电状态 | PMU、电池与蜂鸣器 |

**演示边界**：状态页显示电池电压，不是精确剩余电量。Wi-Fi/BLE 在演示固件中关闭，因此不会展示配对或云端流程。蜂鸣器只能发简短电子音；自然“喵喵”录音需要扬声器/音频电路或由平板播放。离开麦克风页时固件卸载麦克风驱动；这不是量产版实体静音开关。

刷写哈希校验与启动串口日志已通过；串口诊断进入三个页面，麦克风驱动正常且静态环境音量读数在 20–48 之间，状态页显示电池 4.17 V。屏幕外观、实体按键手感和蜂鸣器实际响度仍以现场观察为准。串口字符 `n`/`a` 分别模拟 B/A 键，便于开发调试。

本演示固件已取代板上的语音原型应用，因此当前不会上传语音到网关。旧的语音原型固件保留在 `../M5StickCPlusVoice/firmware/release/m5stickcplus-voice-merged.bin`，可通过其 README 的 USB 刷机命令恢复。刷机前另备份了 NVS 配置分区到本工作区 `work/voice-nvs-before-hardware-demo-2026-10-10.bin`；它可能包含 Wi‑Fi 凭据，因此未放进 outputs。原厂镜像备份也在 `work/`。
