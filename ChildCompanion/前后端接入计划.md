## 接入顺序

1. **本地连接层**：Next.js 服务端代理转发到 `127.0.0.1:8766`，浏览器不保存家长/儿童令牌或供应商密钥。服务端环境变量配置后端地址与本机演示令牌。代理区分家长、儿童请求，并统一超时及错误格式；不在浏览器跨域直连后端。
2. **孩子档案与设备绑定**：读取/保存后端档案、年龄、学段、设备 ID、按键录音开关。前端昵称、兴趣、每周多时段、设备电量/固件在线状态尚无后端支持，继续保留原有前端展示。当前后端只保存一组每日时间窗口且固件不执行定时常开收音。
3. **家长当日数据**：接 `inputs`、`today`、`daily report`。日报在 19:00 前显示待生成；无可用同伴事件时显示信息不足。逐字稿只展示当日可用内容；更正调用现有接口并刷新报告版本。情绪比例按用户要求保留前端数据。
4. **儿童问答**：首页语音按钮进入聊天页，聊天页使用真实录音服务；录音→ASR 文字确认→Agent 文字→TTS MP3。保留孩子文字与回答仅在页面当前会话内；退出时清理页面录音和音频。TTS 失败仍显示文字。
5. **故事 TTS**：继续使用本地故事和插画，补后端受控故事音频接口；播放器以真实音频控制播放/暂停，由用户翻页。页面增加“AI 生成配音”提示；离开页面停止并释放音频。
6. **联调**：先用模拟供应商测试前端 API 契约，再用已连接的 M5StickC Plus、火山 ASR/TTS 与 DeepSeek 账号走完整链路。检查家长/儿童权限隔离、当日时区、空转写、502/503、无报告、旧 session、断网及 iPad 麦克风授权。
