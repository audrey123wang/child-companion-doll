# ChildCompanion 本机前后端联调

本目录是前端原包的可编辑副本，与当前项目的 `backend/` 配套。原包位于另一个工作目录，未被覆盖。

## 启动

先在项目根目录启动后端。本机密钥已存于权限受限的 `backend/.env`，启动脚本自动读取；前端和固件不包含密钥：

```zsh
backend/run_local.sh
```

再在另一个终端启动前端：

```zsh
cd outputs/ChildCompanion
npm install
BACKEND_BASE_URL=http://127.0.0.1:8766 npm run dev
```

打开 `http://127.0.0.1:3000`。如果后端改用了 `LOCAL_PARENT_TOKEN` 或 `LOCAL_CHILD_TOKEN`，也要在启动前端时设置相同的服务端环境变量。浏览器只请求 Next.js 的 `/api/backend/*`，不会拿到角色令牌或云服务密钥。两个服务都应只监听本机地址。

娃娃 USB 桥接在第三个终端继续运行：

```zsh
python3 outputs/M5StickCPlusListeningFirmware/usb_bridge.py \
  --api-mode scene --gateway http://127.0.0.1:8766
```

## 本轮已接入

- 家长端设置孩子年龄和学段、绑定设备、开启或暂停按键留言；今日概览和日报读取后端数据。当天可见 ASR 转写并更正；日报可随时手动生成，未手动生成时 19:00 自动生成，展示报告观察、主要同伴问题及家长引导建议。
- 儿童首页按键录音使用浏览器麦克风，生成 16 kHz 单声道 PCM16 WAV。ASR 文字在浮窗确认后提交独立的 DeepSeek 问答接口；回答先显示在角色气泡，再播放 MP3，语音失败不隐藏文字。首页问答不依赖当晚的故事推荐。
- 原有故事与插画保留；首页绘本和故事列表逐页调用火山 TTS。用户可播放、暂停和翻页，离开页面会停止播放。
- 情绪比例、周报、通知、每周多时段设置以及设备遥测继续显示前端原有数据。这些数据不来自当前后端。当前固件只支持按键留言；家长端设置的每日时段还没有控制固件常开收音。

## 已知验证边界

故事后讨论仍需要当日有同伴相处事件，且家庭时区已到 19:00；首页直接问答可在此前进行，也可在没有同伴事件时进行。浏览器录音需要本机地址或 HTTPS 及麦克风授权。当前前端是本机单家庭实验，不具备正式登录、儿童账号和互联网部署能力。

本项目的 macOS 构建已通过 `next build --webpack`；后端模拟供应商测试已通过。真实供应商账号、iPhone/iPad 麦克风及娃娃端到端播放仍需现场验证。
